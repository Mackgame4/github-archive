# Prodigy RP Server

## ⚙️ DEV:

## 📷 Mode of usage (for nooders like me)
- Clone the repo to an empty folder
- Download the [fivem server artifacts](https://runtime.fivem.net/artifacts/fivem/build_server_windows/master) and drop it on the folder
- <b>Attention: try not to fuc* the .gitignore by replacing it, and remember to copy and rename the ServerCFG.cfg to server.cfg</b>
- Then execute go to "./UI" folder and execute the build.bat to build the UI
- And finally execute the ServerStarter.bat to start the server
