# storeApp

> Based on https://github.com/ittus/vuejs-firebase-shopping-cart

## Get Started

``` bash
# install dependencies
npm install

# serve with hot reload at localhost:8080
npm run serve

# build for production
npm run build
```

Or use `yarn`
``` bash
yarn install
yarn serve
```

Change your DB information on the `.env` file related to your firebase app.
You can use data in `data/` folder to import to `products` node in your firebase app.
